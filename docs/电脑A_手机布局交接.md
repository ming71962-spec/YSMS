# 电脑 A：手机布局与可读性

本轮改动集中在 App.tsx 和新建 kitchen-layout.css，没有修改 src/data、FoodArt.tsx、engine.ts、store.ts、类型或依赖。

手机顶部保留发现菜谱/食材关系图；食材面板默认收起，显示选中及常备数量，展开可搜索、选料、调整常备项。选择完成后收起面板、聚焦并滚动至结果区域。窄屏菜谱改为单列，增大正文和操作区域，原谱照片/主料示意的标记继续保留，食物不做灰度处理。

复用现有 React、Lucide、React Flow，不新增第三方依赖。数据映射仍由 B 维护；A 的排列样式只处理显示，不改变食材含义或来源。

浏览器核对：390px 预览下展开、选择西红柿/鸡蛋、完成选料、结果聚焦、关系图与详情弹窗；320px 和 1440px 下页面无水平溢出；桌面食材面板仍可见，图片加载检查无损坏。尺寸指浏览器 viewport 设置值，滚动条会使文档内容宽度略小。

后续 B 修改图片和菜谱时无需删除或改写本轮布局。若新增长名称、图片类型或字段，请同时告知 A 检查手机显示。人数换算与新菜谱不属于本轮实现。
