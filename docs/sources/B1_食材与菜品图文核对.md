## 一、产品目标与核对说明（对应《产品定位与使用场景》第 8 节）

1. **服务对象与情境**：面向使用“用手边食材安排下一顿饭”流程的家庭做饭者（选料 → 找菜 → 组桌 → 看做法）。这是项目当前已确定的方向与设计假设，本次核对属于直接可观察的数据与图文准确性问题。
2. **解决的问题**：此前 `public/art/green-pepper.webp` 实图为红甜椒，导致“青椒”卡片与“酸辣土豆丝”主料示意均出现图物不符；同时 `visuals.json` 中全部 26 项 `culinary-assets` 食材误复制了“酱油包装为通用示意”备注，白糖使用方糖图而非更贴合中餐的砂糖图，鸡翅中缺少原图路径记录。修正后避免用户在快速选料和看主料示意时被错图误导，并为 B2 补图建立逐项清单。
3. **验证与边界**：通过逐张人工目视检查全部 32 张 `.webp` 图像、核对上游固定提交 `catalog.json` 与原图、补充 `tests/engine.test.ts` 自动化一致性校验，以及本机 `pnpm dev` 页面实测验证。本次（B1）仅修正已有错图、同固定提交内更准确的替换及元数据记录，**未引入新的第三方仓库或新增菜谱**，其余缺图与形态待替换项留待 B2 分批补齐。
